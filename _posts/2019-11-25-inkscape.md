# MCP 🐿️

<div class="encart blue" markdown="1">
Installed by **cline** — setup summary
</div>

- [inkscape-mcp-server]( https://github.com/jjjsood/inkscape-mcp-server#inkscape-mcp) — MCP server (STDIO, FastMCP) exposing ~87 typed tools: inspect / safe-edit / validate / render / export SVG, snapshot + reversible by construction.

**Install** — `uv` is provided by [home-manager](https://github.com/nix-community/home-manager) (`home.packages = [ ... uv ... ]`, then `home-manager switch`)

```bash
$ uv tool install --from git+https://github.com/jjjsood/inkscape-mcp-server.git inkscape-mcp
$ command -v inkscape-mcp
/home/yves/.local/bin/inkscape-mcp
```

**Inkscape 1.4.x on PATH** (AppImage, symlinked into `~/bin`)

```bash
$ ln -s /home/yves/app/Inkscape-1.4.4.AppImage /home/yves/bin/inkscape
$ inkscape --version
Inkscape 1.4.4 (dcaf3e7, 2026-05-05)
```

**Register in cline** (`~/.cline/data/settings/cline_mcp_settings.json`)

```json
{
  "mcpServers": {
    "inkscape": {
      "command": "/home/yves/.local/bin/inkscape-mcp",
      "args": [],
      "environment": {
        "INKSCAPE_MCP_WORKSPACE_ROOTS": "/home/yves/MCP/inkscape-workspace"
      },
      "timeout": 600,
      "disabled": false
    }
  }
}
```

`INKSCAPE_MCP_WORKSPACE_ROOTS` is the **required** sandbox — the server only reads/writes inside that directory.

**Verify**

```bash
$ INKSCAPE_MCP_WORKSPACE_ROOTS=/home/yves/MCP/inkscape-workspace inkscape-mcp </dev/null
# boots and exits cleanly (STDIO)
# `diagnose_runtime` → inkscape_available: true, version [1, 4, 4], meets_minimum: true
```

> Restart cline to pick the server up. Upgrade with `uv tool upgrade inkscape-mcp`. Live mode is on by default (`INKSCAPE_MCP_LIVE_ENABLED`) for controlling a running Inkscape GUI.
