> [Things You Should Know About Fragment URLs](https://blog.httpwatch.com/2011/03/01/6-things-you-should-know-about-fragment-urls/) (#) <!--more-->
- A Fragment URL Specifies A Location Within A Page
- Fragments Are not Sent in HTTP Request Messages
- Anything After the First # is a Fragment Identifier

<div class="encart blue" markdown="1">
**uri** - unified ressource **identifier** - what is this ressource - the broader definition

**url** - unified ressource **locator** - where is this ressource? (also a uri)

**urn** - unified ressource **name** - isbn could be one type (also a uri)
