# Le Noyau

un element qui nous envoie sur 0: f(v) => 0 (on perd de l'information sir la fonction n'est pas bijective).
Le noyau est constitué par tous les éléments/vecteurs qui nous envoie sur 0.

Si la fonction est lineaire, le noyau est une droite (car si u est element du noyau, l*u l'est aussi)
